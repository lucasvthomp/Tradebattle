The target was a practical multi-user sanity check across desktop and mobile code paths, including closed-market and invalid-asset conditions.

## Findings fixed

### High — footer could float above a blank page gap

The footer was mounted outside the app shell, which allowed short pages to leave empty space below it. It now renders inside the shell’s flex column and is pushed to the bottom of the available viewport without creating a second trailing gap.

Files: `client/src/App.tsx`, `client/src/components/layout/layout.tsx`, `client/src/styles/site-theme.css`

### High — mobile chat button had no usable panel

The mobile chat control could toggle state, but the chat panel was hidden at the same breakpoint. The panel now renders as a full-width mobile sheet and remains a fixed desktop sidebar at larger widths.

Files: `client/src/components/layout/layout.tsx`, `client/src/styles/site-theme.css`

### High — old blue/green theme variables could override purple/gold tokens

Several legacy site variables still pointed at older blue and mint values. Shared shell, panel, edge, text, footer, and arena variables now resolve through the centralized `--tb-*` palette so the visual system can be changed from one place.

Files: `client/src/styles/site-theme.css`, `client/src/components/layout/simplified-sidebar.tsx`

### High — tournament creation could strand a buy-in

Creation debited the organizer before all related records were guaranteed. The debit, log entry, tournament row, and creator participant row now run in one transaction with a row lock, so any later failure rolls the balance back.

File: `server/storage.ts`

### High — execution endpoints accepted the wrong asset class

The search UI distinguished stocks and crypto, but direct purchase/sell requests did not enforce the arena’s selected market. The server now rejects crypto symbols in stock arenas and stock symbols in crypto arenas, with clear user-facing errors.

File: `server/routes/api.ts`

### Medium — profile images and presence indicator were inconsistent

Broken or missing profile images could fall back to initials or a broken image, and the online badge could collide with the top edge. All relevant surfaces now use the shared default broker avatar and place presence at the bottom-right of the image.

Files: `client/src/components/ui/avatar-with-status.tsx`, `client/src/components/chat/ChatSidebar.tsx`, `client/src/pages/profile.tsx`, tournament participant components

### Medium — optional chart canvas type broke clean type checks

The chart renderer relied on a type package that is not installed in the current workspace. A narrow local canvas-target interface now keeps the renderer typed without changing runtime behavior.

File: `client/src/components/trading/RoundedCandleSeries.ts`
